singlet

Install

curl -fsSL https://singlet.xroma.dev/install.sh | sh

Use

press glow → call  ·  ring → answer  ·  in call → mute
press ×2 hang up  ·  cancel a dial

Light

dark peer offline
glow peer free — press to call
slow pulse dialing…
fast blink peer calling — press to answer
breathing voice line live
dim red muted
2 pulses → dark peer busy
flash → dark missed call

Flows

call → answered →
answer →
hang up →
cancel →
mute → →
busy peer busy → →
missed no answer → →

Uninstall

curl -fsSL https://singlet.xroma.dev/uninstall.sh | sh
